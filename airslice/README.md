# AirSlice add-on

Print MakerWorld, Printables and Thingiverse models on your offline Bambu Lab printer, from the Home Assistant sidebar or your phone. **Alpha.**

- Paste or share a model link, choose the profile and plate, print
- Slices on your server with OrcaSlicer; the printer never needs internet
- A queue by printer type, live status, AMS filament, camera and controls
- Notifications through Home Assistant, Telegram, ntfy or the browser
- API keys for automations

See the Documentation tab for setup.
